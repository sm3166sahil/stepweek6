# STEP SEM-3 Week 6 — Classes and Objects (Category C)

Each problem has a separate `.java` file with a matching public class and its own `main()` method.

- `Practice/`: 5 practice problems from the Classes and Objects Revision PDF.
- `Assignment/`: 5 assignment problems from the Classes and Objects Assignment PDF.

## Compile and run
Open PowerShell in the folder containing the Java file, then run:
```powershell
javac Problem1_StudentPlacementRecordManagement.java
java Problem1_StudentPlacementRecordManagement
```
Replace the filename/class name with the program you want to run. No external libraries are required.
